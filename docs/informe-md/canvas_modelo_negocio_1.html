El Canvas de Modelo de Negocio

Diseñado para
Detección de malezas en caña de azúcar — UBP
Diseñado por
Briguera · Juarez · Godoy Cabrera · Guerrero · Iriarte Chamorro · Lagoria
Fecha
Agosto 2026
Versión
1.0

Socios Clave

  • INTA Famaillá — validación agronómica y ensayos de campo
  • EEAOC — relevamientos de malezas y datos históricos
  • UBP — cátedra e infraestructura académica
  • Ingenios azucareros de Tucumán
  • Productores piloto (2‑3 lotes de validación)
  • Proveedores locales de vuelo con drones
  • Comunidad open source (OpenDroneMap, Ultralytics)

Actividades Clave

  • Desarrollo del pipeline de visión artificial
  • Captura y etiquetado de datasets locales
  • Entrenamiento y validación de modelos
  • Diseño del motor de reglas junto al INTA

Recursos Clave

  • Dataset local etiquetado (imágenes + máscaras)
  • Modelos entrenados (YOLOv8/v11, DeepLabV3+)
  • Infraestructura cloud (cómputo, PostGIS)
  • Conocimiento agronómico validado (INTA/EEAOC)
  • Equipo de 6 estudiantes de Ing. en Informática

Propuesta de Valor

  • Reducción del 20‑35 % en consumo de herbicidas (tasa variable)
  • Detección temprana de malezas por especie
  • Estimación de rendimiento por parcela
  • Plataforma 100 % open source, infraestructura < USD 200
  • Recomendaciones agronómicas trazables y validadas

Relación con Clientes

  • Acompañamiento técnico directo en la etapa piloto
  • Capacitación a productores y técnicos
  • Dashboard de autoservicio para consulta de reportes
  • Soporte vía convenio institucional (INTA/EEAOC/UBP)

Canales

  • Dashboard web geoespacial y API REST
  • Convenios institucionales con INTA y EEAOC
  • Difusión académica (publicaciones, defensa del PTI)
  • Repositorio público en GitHub

Segmentos de Clientes

  • Productores cañeros de Tucumán (pequeños y medianos)
  • Ingenios azucareros
  • Cooperativas agrícolas del NOA
  • Instituciones de investigación (INTA, EEAOC)
  • A futuro: limón, arándano, frutilla, tabaco, soja, garbanzo

Estructura de Costos

  • Infraestructura cloud (< USD 200 durante el PTI)
  • Costo de vuelos de relevamiento con drones
  • Tiempo de desarrollo del equipo (recurso académico)
  • Sin costos de licenciamiento — stack 100 % open source

Fuentes de Ingresos

  • Durante el PTI: ninguna — proyecto académico sin fines de lucro
  • A futuro: servicios de soporte y capacitación
  • Convenios de transferencia tecnológica con INTA/EEAOC
  • Modelo freemium: dashboard básico gratis + reportes avanzados pagos
  • Licenciamiento de datasets etiquetados a terceros

Lectura del modelo

El proyecto se mantiene en fase académica y sin fines de lucro durante el PTI: el bloque de ingresos queda deliberadamente vacío para ese período. El valor del canvas está en anticipar el camino hacia una iniciativa sostenible — spin‑off universitario, convenio de transferencia con INTA/EEAOC, o servicio a ingenios y cooperativas — una vez validado el sistema en campo.
